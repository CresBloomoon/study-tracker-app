# ADR-003: 学習時間は「秒表示・分保存（切り上げ）」とする

## Status
Accepted

## Date
2026-01-06

## Context
CPA-Dashboard-Core v1 では、学習時間を主要な評価指標として扱う。

ストップウォッチ機能により、ユーザはリアルタイムで学習経過を確認するため、
秒単位での表示は達成感・把握性の観点から有用である。

一方、学習記録（StudyLog）は日次・週次集計の基礎となる一次データであり、
過度な精度は集計・表示・DB設計を複雑化させる。

v1においては、学習時間の厳密な秒精度よりも、
設計の単純性・集計の安定性・UXの一貫性を優先する。

## Decision
v1における学習時間の扱いを以下の通り定める。

- タイマー表示は **秒単位** とする
- 内部計測は elapsedSeconds で行う
- StudyLog に保存する時間は **分単位** とする
- 秒から分への変換は **切り上げ**で行う

durationMinutes = ceil(elapsedSeconds / 60)

markdown
コードをコピーする

## Consequences
### Positive
- UIはリアルタイム性と達成感を提供できる
- DB・集計処理が単純になり、実装ミスを防ぎやすい
- 最大誤差は +1分に限定され、実用上の影響は軽微
- 日次・週次集計の一貫性が保たれる

### Negative / Trade-offs
- 秒単位での厳密な学習時間管理はできない
- 短時間の学習が切り上げにより過大評価される可能性がある

### Mitigations
- 学習時間は自己管理指標であり、秒精度の厳密性は要件としない
- より高精度な管理が必要になった場合は、
  秒保存への移行を **新しいADRとして判断** する
